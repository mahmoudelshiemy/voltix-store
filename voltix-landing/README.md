# Voltix Electronics Landing Page

Responsive Arabic RTL landing page for a fictional electronics store, built with React, TypeScript, Vite, and Tailwind CSS v4.

## Requirements
- Node.js 20+
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
- Replace the demo WhatsApp number `201115932356` with the store's real number.
- Product names, prices, ratings, and product photos are demonstration content; replace them with approved store data.
- Product photos are loaded from Unsplash and therefore require an internet connection.

## Included interactions
- Responsive navigation and mobile menu
- Product category filtering
- Product search
- Add-to-cart counter and toast notification
- Favorite toggles
- WhatsApp contact links
